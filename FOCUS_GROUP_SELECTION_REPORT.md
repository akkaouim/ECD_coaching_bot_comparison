## Notes on Detection Methods

### AI Tool Usage Detection
The script detects AI tool usage based on:
- Very long user responses (>200 characters, multiple instances)
- Repetitive response patterns
- AI-related keywords in messages
- AI-related tags in message metadata

### Loop Blocking Detection
The script detects loop blocking based on:
- Repetitive assistant messages (same content appearing 3+ times)
- Multiple very short user responses (<5 characters)
- Error messages or "I didn't understand" patterns appearing multiple times
